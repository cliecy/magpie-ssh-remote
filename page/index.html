MAGPIE · SSH

把本地模型带到服务器

通过 SSH 连接，在服务器上的 agent 中使用这台电脑的 Magpie。

服务器

连接会在后台保持。断线后每 15 秒重试；关闭插件后断开。

添加服务器

沿用 ~/.ssh/config 中的密钥与跳板机。首次连接请先在终端 ssh 到该主机，确认指纹及免密登录。保存修改会断开当前连接。

保存后即可连接。

接入服务器上的 agent

复用服务器 Magpie 本体的 agent 接入、模型同步和恢复逻辑。本体支持的 agent，可通过同一入口配置。

服务器需先安装 Magpie 和 curl。「配置 / 启动」会添加本机模型源；网关未运行时，使用本体的 daemon 命令启动服务。密钥与跳板机仍沿用 SSH 配置。

检测后在这里显示服务器 Magpie 支持的 agent。列表由本体提供。

接入后按本体提示重启 agent，再直接运行原命令。新增 agent 支持随服务器 Magpie 版本更新，插件无需新增适配器。
