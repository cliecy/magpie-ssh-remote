MAGPIE · SSH

把本地模型带到服务器

通过 SSH 连接，在服务器上的 agent 中使用这台电脑的 Magpie。

正在连接后台助手…

服务器

连接会在后台保持。断线后每 15 秒重试；关闭插件后断开。

添加服务器

沿用 ~/.ssh/config 中的密钥与跳板机。首次连接请先在终端 ssh 到该主机，确认指纹及免密登录。保存修改会断开当前连接。

保存后即可连接。

接入服务器上的 agent

安装独立启动命令。在服务器的项目目录执行它，即可使用上方模型。修改模型后，保存并重新安装启动命令。

Codex~/.local/bin/codex-magpie
Claude Code~/.local/bin/claude-magpie

服务器需要已安装对应 agent 和 curl。原有 agent 配置保留。Mac 需保持联网，Magpie 需持续运行。
