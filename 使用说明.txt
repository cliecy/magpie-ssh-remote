Magpie SSH 远端接入 v0.2.0

改为复用服务器 Magpie 原生 agent 适配器。

服务器先安装 Magpie，然后在插件中：
1. 保存主机、模型并连接。
2. 检测本体及 agent。
3. 配置 / 启动远端 Magpie。
4. 填写任意本体支持的 agent ID（例如 omp、pi、dsh），接入所选模型。
5. 按本体提示重启，再直接运行 agent 原命令。

恢复配置会调用 magpie <agent> default。无需逐个维护配置文件适配。
断开隧道不会自动恢复 agent 或停止服务器上的 Magpie 服务。
更多安装、限制及测试说明请阅读 README.md。
